# 🏗️ BuildNexus — AI-Orchestrated Construction Operating System

> **"Build Smarter. Pay Fairly."**  
> An end-to-end ConTech platform connecting **Contractors & Builders**, **Verified Labor Squads**, and **Material Suppliers** through a unified tripartite ecosystem—powered by **Spatio-Temporal Graph Neural Networks (ST-HGNN)**, **Kinematic Action Recognition (ST-GCN)**, and **Multi-Agent JIT Scheduling**.

## 🌟 Core Value Propositions
1. **Tripartite Combinatorial Synchronization**: Matches Site Milestones $\leftrightarrow$ Verified Labor Gangs $\leftrightarrow$ Material Deliveries using Spatio-Temporal Graph Attention.
2. **100% Guaranteed Fair Wages**: Laborers receive their full promised earnings with **0% platform deduction**; transparent split ledger for team Sardars.
3. **In-App Private Negotiation**: Phone numbers are automatically masked in chat to prevent off-platform bypass and protect wholesale pricing.
4. **Perishable Fleet & JIT Dispatch**: Live tracking of Ready-Mix Concrete batch age ($t_{\text{batch}} < 90\text{ min}$) and OTP-secured handover.
5. **AI SuperCore Suite**:
   - **NexusBot**: Real-time BOQ and material estimation co-pilot (IS 456 / IS 1200).
   - **ST-HGNN Engine**: Solves 3-way matching under physical transit constraints.
   - **Proof-of-Skill Vision**: Biomechanical video skill grading replacing unverified text resumes.
   - **TFT Price Forecaster**: Multi-horizon probabilistic forecasting for cement and steel.

## 🚀 Quick Start (One-Click)

### Option 1: Double-Click the Launcher
Simply double-click:
```bash
Start-BuildNexus.bat
```
This automatically launches your browser to `http://localhost:3000` and starts the development server.

### Option 2: Command Line
```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Generate Prisma Client
npx prisma generate

# 3. Start Development Server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

- **Command Center (`/`)**: Real-time project overview, active sites, stock depletion warnings, and live perishable delivery alerts.
